# custom_natural テストセット

BSRNet / BSRGAN (×4 超解像) の評価用テストセット。  
**ライセンス要件**: CC0 または商用利用可能なライセンスのみ（Unsplash Lite は訓練セットと重複するため使用しない）。

---

## 収集指針

### 枚数: 20〜30 枚

- Set5（公式ベンチマーク）は 5 枚で安定性が低い
- 20〜30 枚で PSNR の標準誤差が ±0.1 dB 以下に収まる
- 手動収集の手間と統計的信頼性のバランス点

### カテゴリ構成（各 4〜6 枚）

| カテゴリ | 理由 |
|---|---|
| 植物・芝・木の葉 | 細かい周期パターン → SR 復元力の評価に直結 |
| 建築・レンガ・柵・タイル | 水平・垂直エッジ → アーティファクト判別が容易 |
| 布・毛並み・羽 | 斜めテクスチャ → エイリアシング耐性の確認 |
| 水面・空・霧 | 低周波領域 → 平坦部のノイズ・ぼけ判別 |
| 動物・鳥・昆虫 | 輪郭と細かい毛/鱗の混在 → 汎用性確認 |

### 避けるべき画像

- CGレンダリング・過剰シャープ加工済み（SR の特性とズレる）
- 元からぼけている・重度 JPEG 圧縮（ground truth が汚染される）
- 同一シーン・同一構図の連続（評価バイアスが乗る）
- 著作権・商用利用に疑問があるもの

### サイズ: **768px 以上を推奨**

BSRGAN は ×4 モデルなので LR = HR ÷ 4:

| HR | 生成 LR | 評価の余裕 |
|---|---|---|
| 512px | 128px | 最小限 |
| 768px | 192px | 推奨 |
| 1080px | 270px | 余裕あり |

大きすぎる画像はタイル推論で対応できるため上限なし。

### フォーマット

- **PNG 推奨**（ロスレス、ground truth が劣化しない）
- JPEG を使う場合はクオリティ 95 以上
- カラー（RGB）で収録する → 評価時に RGB / グレースケール 両方で PSNR を計算可能

### カラーかグレースケールか

BSRNet / BSRGAN は `in_nc=3`（RGB モデル）。評価は **カラーで行うのが正しい**。  
ただし本プロジェクトの最終用途（鉛筆スケッチ処理）はモノクロなので、  
カラー PNG で収録し、評価スクリプト側で RGB / グレー 両方の PSNR を出力する構成を推奨:

```python
img_rgb  = Image.open(path)             # RGB評価
img_gray = img_rgb.convert('L')         # グレー評価
```

## 使い方

画像を収集してこのディレクトリに PNG / JPEG で配置し、config の `dataroot_test` を更新する:

```json
// options/train_bsrgan_x4_psnr_unsplash.json
"dataroot_test": "testsets/custom_natural"
```

```bash
# 動作確認（画像が正しく読み込まれるか）
python scripts/train_bsrgan_psnr.py \
    --config options/train_bsrgan_x4_psnr_unsplash.json \
    --max_iters 100 --datasets unsplash_lite
```
